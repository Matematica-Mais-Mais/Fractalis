# 🌀 Fractalis - Interface Web

Interface interativa para visualização de fractais matemáticos gerados através do Método de Newton. Construído com Python, Flask e renderizado em HTML/Canvas.

## 🚀 Como Baixar e Usar (Sem precisar instalar Python)

1. Vá até a seção de [Releases](../../releases/latest) aqui no GitHub (menu lateral direito).
2. Baixe o arquivo **`app.exe`**.
3. Dê dois cliques no arquivo baixado. Ele iniciará o processo em segundo plano e abrirá a interface automaticamente no seu navegador padrão.
